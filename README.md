# Central European Conference — website

Live: https://ceconference.uk (hosted on Netlify, deploys automatically from the `main` branch).

- `index.html` — current "coming soon" placeholder for CEC 2027 (20 March 2027, LSE, London).
- Domains are registered at GoDaddy: `ceconference.uk` points to Netlify, `ceconference.co.uk` redirects to it.
- `archive/` — past editions (2022, 2023, 2025) rebuilt in the new visual style from the old Webflow sites. Images are in `archive/img/`, shared styles in `archive/archive.css`.

Any change merged into `main` goes live within a minute or two.
