How to add it

  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste → Save changes at the bottom of the page.
  2. Outlook: Settings → Mail → Compose and reply (or Signatures) → New signature → paste → Save.
  3. Apple Mail: Settings → Signatures → + → untick "Always match my default message font" → paste.

Send yourself a test e-mail to check it. "Copy HTML code" is only for clients that ask for the code itself.
